## Findings considered and rejected

- `shellcheck` SC2221/SC2222 at `install:245-247` (dead `""` pattern): cosmetic on its own; now removed as part of plan 004 because it blocks the lint gate.
- fzf picker: README claims "Confirming an empty selection changes nothing". Verified on fzf 0.74.3 via a pty that `accept` with zero selected rows outputs nothing, so the claim holds. Not a finding.
- Making the fzf picker cycle all four States: would change the documented key bindings. Deferred; `--set` covers it.
- `package.json` cruft (`"private": "true"` as a string, empty `author`/`keywords`, `directories.doc`, `license: ISC`): harmless. Fix by hand any time; not worth a plan.
- `plans/*.patch` for DONE plans 001/002: dead weight now that the changes are committed. Delete whenever convenient; not worth a plan.
- `install:125` `describe()` assumes a single-line `description:` in SKILL.md frontmatter; a folded YAML description would show blank. All three skills are single-line today. See direction note 1.
- `install:211` fzf `--preview` breaks if the repo path contains a space. `~/src/skills` does not. Not worth a plan.
- `pr-draft/SKILL.md:39-42` diffs against `origin/$BASE` without fetching first, and uses fixed `/tmp/pr-body*.md` paths. Low impact; a one-line "fetch first" edit any time.
- `preview.html` loads Geist from Google Fonts: documented as by-design in `pr-draft/SKILL.md:83` with local fallbacks.
- Python fallback in `write_overrides` does not close the file before reopening for append (`install:110-111`): CPython closes on refcount drop; works. Not a finding.

## Direction (options, not ranked against the bugs above)

1. **`./install --check`**: validate each `skills/*/SKILL.md` (frontmatter `name` equals the directory, single-line `description`, valid `disable-model-invocation`), report Links that point elsewhere or dangle (plan 005 adds the `owns_link` primitive), report Overrides for skills no longer in the repo, and warn when `node_modules` is missing for `pr-draft`'s preview (`preview:52` is the only thing that checks today). Evidence: `install:125` fragility; `preview:52`. Effort S–M. Trade-off: more surface in an already 350-line script; consider splitting `install` into functions per mode first.
2. **Bring the rest of the skills home**: `~/.claude/skills` on this machine has ~40 symlinks into `~/.agents/skills` and real directories (`caveman`, `caveman-compress`) that this repo does not manage, against a README whose stated purpose is one portable collection. Trade-off: some are third-party (a Vercel plugin, `agent-browser`) with their own update path, so a "sources" policy (vendored vs. linked-from-elsewhere) is needed before importing. Effort M for the policy, then S per skill.
3. **Reuse the preview renderer**: `pr-draft/preview` is a general "Markdown to Geist HTML" tool with escaping and offline embedding already solved. `improve`-style plans in `plans/` and ADRs in `docs/adr/` could be previewed the same way. Trade-off: it would pull the tool out of the `pr-draft` skill into a shared location and the Managed Block assumptions with it. Effort S for a `--title`-only generalisation.
   _Update 2026-09-17_: the shared location now exists as `artifact/render` (used by `web-research`, with a citation gate, `--no-open`, and the pnpm hint). `pr-draft/preview` was left untouched so plan 006's excerpts stay valid; after 006 lands, reduce `preview` to template discovery plus a call to `artifact/render`, and delete `pr-draft/assets/preview.html`.
